# DL Exp 6: Image Captioning

Image captioning with a CNN encoder + RNN decoder, comparing attention variants.

- Key techniques: encoder-decoder with attention, adaptive attention mechanism, AdamW optimization
- Variants: baseline (no attention), attention, adaptive attention, with optimizer/attention ablations
- Artifacts: `caption.ipynb`, `train.ipynb`, `test.ipynb`, `create_input_files.ipynb`, model/training modules (`models.py`, `solver.py`, `datasets.py`, `utils.py`)
